# market-radar 大盘月线MACD雷达

每月线级别扫描全球主要指数 MACD 状态,自动分类:

- 🟢 **金叉健康**:月线柱回升,可做多
- 🟡 **金叉转弱**:柱连续收缩,警惕
- 🟡 **金叉垂死**:柱贴零轴,即将死叉
- 🔴 **刚死叉**:死叉第1-2月,回避/清仓
- 🟠 **死叉收敛**:绿柱缩短,可能修复

## 覆盖指数

A股8(上证/上证50/深成/创业板/沪深300/中证500/中证1000/科创50)
港股3(恒指/恒生科技/国企指数)
美股3(纳指/标普/道指)

## 本地使用

```bash
python3 mradar.py            # 全量扫描
python3 mradar.py sh000001   # 单指数详情(近8月轨迹)
```

## 自动报告(GitHub Actions)

每日北京时间 08:30(开盘前)与 15:35(收盘后)自动运行,
报告输出到 [reports/](reports/) 目录(latest.md = 最新)。

## 策略联动

上证月线死叉 = 半导体策略空仓(回测 2020-2026:+131%,年化13%,
月线开关有效;日线波段为负贡献,应去掉)。
